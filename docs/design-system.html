Design system v3

MediShelf-Sync

Built on the kusuri-dansu, the Japanese apothecary chest. Every medicine is a drawer; the handle colour tells you if it is safe. Use these tokens and components for every new screen, e-mail and printed item.

Colour

Status is never shown by colour alone: always pair a handle with the words Safe, Use soon or Expired. All text pairs meet WCAG AA contrast in both themes.
